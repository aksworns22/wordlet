# 스프린트 1 회고 (9/25 ~ 10/2)

## 1. 문제와 목표

**목표:** 단어 학습에만 효율적으로 집중할 수 있는 앱(환경)을 만든다.

**문제**

- 안키는 알고리즘이 좋지만 사용하기 너무 어렵고, 안드로이드 UI가 오래되어 경험이 별로다.
- 안키만큼 알고리즘이 좋은 다른 앱은 광고, 구독, 계정 등 불필요한 요소가 많다.
- 무료이고 광고·구독이 없는 단순한 앱은 좋은 학습 알고리즘이 없다.

**타깃:**

- 안키의 효과는 알지만 사용이 어려워 그만둔 사람.
- 광고·구독 없이 무료로, 효과적인 단어 학습을 원하는 사람.

## 2. 한 일

- FSRS 알고리즘 기반의 실행 가능한 앱을 만들었다.
- 지인 대상 비공개 테스트로 정성 피드백을 받았다. 다만 테스트한 사람들이 타깃이 아닌 문제가 있다.
- 단어장 불러오기를 MVP 범위에 추가했다. 처음에는 단어장 개념과 불러오기를 빼고 단어를 직접 추가하는 구조만 생각했지만, 10명 정도와 이야기했을 때 절반 이상은 단어 불러오기를 언급했다. 이 앱은 한 번 써봐야 효용을 체감하는 특성이 있어서, 불러오기가 만족스러운 첫 학습까지의 장벽을 낮춘다고 판단했다.

## 3. 배운 점

- 기능을 빼는 것 자체가 목적이 아니다. 기능을 뺀다고 사용자가 더 쉽게 이해하거나 경험이 좋아지는 것은 아니었다. 사용자가 핵심 가치(효율적인 단어 학습)를 체감하기까지 걸리는 시간을 줄인다면 넣을 수 있다.
- 타깃이 아닌 사용자의 요청은 앱의 방향과 맞는지 좀 더 신중하게 판단하고 반영한다.
  - 단어장 불러오기는 앱의 목표(단어 학습에만 효율적으로 집중할 수 있는 환경)에 부합한다고 생각해서 적용했다.

## 4. 받은 피드백

### 다음 스프린트 개선

- 단어장을 불러오는 과정이 어렵고 불편하다
- 단어 추가가 어느 단어장에 되는지 헷갈린다
- 단어가 몇 개 있는지 표시

### 보류

- 무제한 학습이 아쉽다
- 알아요/몰라요로 버튼 단순화
